# Cats vs. Dogs Classification

This is a coursework project that trains image classifiers to distinguish cats
from dogs. The main notebook compares custom convolutional neural networks
(CNNs) with a ResNet50 transfer-learning model.

## Start here

1. Open `notebooks/cats-vs-dogs-classification.ipynb`.
2. In VS Code, open this project folder as the workspace so notebook paths use
   the project root.
3. Run notebook cells from the top in order. Sections 9–13 rely on variables
   created by earlier sections.
4. The CNN and optimizer comparison epoch limits are currently 5. A full run
   can still take a while.
5. After changing data loading or shared functions, restart the kernel and
   rerun from the top. This prevents old in-memory code and datasets from being
   reused.
6. Check that results were generated by the latest run before using them in a
   report; notebook outputs and CSVs can be stale.

### What goes where?

- **`data/`** — original cat/dog images and their dataset documentation.
- **`notebooks/`** — the main interactive experiment.
- **`docs/`** — the research paper used as background.
- **`models/`** — saved trained model files.
- **`results/figures/`** — generated plots.
- **`results/metrics/`** — CSV metric tables.
- **`results/training/`** — training history data.

The image folders and generated model files are large/local assets and are
excluded from Git. Keep the dataset's license and source documentation with the
dataset.

## Notebook sections

1. Setup and locate the dataset.
2. Load and clean image labels.
3. Visualize the dataset.
4. Split data into training, validation, and test sets.
5. Prepare data augmentation.
6–8. Build, train, and evaluate the ResNet50 transfer-learning baseline.
9. Compare custom CNN configurations.
10. Compare optimizers and learning rates.
11. Compare the CNN and ResNet50 results.
12. Test model robustness to image distortions.
13. Save result tables and training histories.

Use the validation set to select models and settings. Keep the test set held
out for final evaluation.

## Dataset and file locations

The notebook looks for the dataset under
`data/kaggle-cats-and-dogs/PetImages/`. Alternatively, set the `PET_DIR`
environment variable to the absolute path of the folder containing `Cat/` and
`Dog/`.

The notebook writes results under `results/` and saves the ResNet50 model to
`models/resnet50-frozen.keras`. Re-run the relevant notebook sections to refresh
those outputs.

## Safe project maintenance

- Do not delete image data, dataset license files, reference papers, or result
  files unless you have confirmed they are backed up or reproducible.
- Before large changes, make a backup or use version control.
- Make small, focused edits and run a quick data/training smoke test before a
  long experiment.
- Keep names descriptive and consistent: lowercase words separated by
  hyphens, such as `optimizer-comparison.csv`.
- If you move project folders, update notebook paths and run the notebook from
  the project workspace root.
